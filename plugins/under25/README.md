# under25

Keeps Claude's replies short and simple.

- Routine replies are 25 words or fewer, in plain B1-level English. No
  minimum, no padding.
- Ask only for simple English, and you get plain words with the full detail.
- Drafts, reviews, reports and code keep their full format. Only the text
  around them is short.
- No technical terms unless they are truly needed, and then with a short
  plain hint.

Claude still does the full work. Only the reply you read is short.

## Use

Ask for short or plain answers ("keep it short", "B1 English", "no jargon"),
or run the skill by name. To use it in every session, add this line to your
`CLAUDE.md`:

```
Always follow the under25 skill: routine replies in 25 words or fewer, B1-level English.
```

## What it runs and sends

Nothing. It is a single instruction file. It runs no commands, reads no
files, and makes no network calls.
